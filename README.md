# SplitZy

Split bills, not friendships. Share expenses effortlessly.

## Features

- **Local Storage Persistence**: Your data stays on your device.
- **Group Management**: Create, join, and manage expense groups.
- **Real-time Calculations**: Instant balance updates and settlement logic.
- **PWA Support**: Installable on mobile and desktop with offline support.
- **Theme Support**: Dark and light mode synchronization.
- **Clerk Authentication**: Secure and centered auth experience.

## Tech Stack

- **Framework**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **Auth**: Clerk
- **State/Hooks**: React Query + Custom hooks

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Set up Clerk environment variables in `.env`.
4. Run development server: `npm run dev`
